The Oz Ledger is a national statistics site for Australia, in numbers: population, the economy, jobs, prices and the states, every figure checked against the publication it came from and dated so you can see how fresh it is. All figures are from the ABS, the RBA and the IMF, with source and year shown on every page.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests: the site is static files under `app/`, and `main.ts` hands it in by copying `app/` and `screenshots/` to `/output` and writing `/output/dossier.json`.
